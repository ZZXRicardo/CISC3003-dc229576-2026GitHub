CISC3003 Final Exam Paper 02B

What is completed:
- index.php provides the contact form with browser validation.
- php/send_contact.php sends mail with PHPMailer and uses Post/Redirect/Get.
- composer.json declares the PHPMailer dependency.
- php/mail_config.php contains SMTP settings.

Before testing:
1. Copy this folder into XAMPP htdocs if it is not already there.
2. Open a terminal in this folder and run: composer install
3. Edit php/mail_config.php with your Gmail SMTP address and app password.
4. Open http://localhost/CISC3003-FinalExam-Paper02B/index.php.
5. Capture screenshots for B.01 through B.05 and save them in My Screen Shots.
